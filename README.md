# Laguna Kids Eats

Kids' menus with prices, kids-eat-free nights, opening hours and family happy hours at Laguna Beach, CA restaurants.

**Open the app:** https://westwoodeleven.github.io/laguna-kids-eats/

## Install on iPhone
1. Open the link above in **Safari**.
2. Tap **Share** → **Add to Home Screen** → **Add**.
3. Open **Kids Eats** from your Home Screen. Allow location when asked to sort restaurants closest first.

## How it works
- `index.html` — the app (works offline after the first visit; the map needs a connection).
- `data.js` — all restaurant data (kids menus, deals, hours, happy hours, coordinates). Updated monthly.
- `sw.js`, `manifest.webmanifest`, `icons/` — Home Screen install and offline support.

Map data © OpenStreetMap contributors. Prices and deals change; confirm with the restaurant. Last checked October 2026.
